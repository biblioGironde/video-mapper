Déposer : nouveau calque
Glissez les coins pour déformer, l'intérieur pour déplacer. Cliquez une surface pour sélectionner son calque.

Calques

Un calque = une forme + un média. Glissez un fichier ou un média de la médiathèque sur une forme (scène ou liste) pour l'y placer. Le calque du haut est dessiné au-dessus ; l'alpha des WebM VP9 / HEVC et des PNG est respecté.

    Propriétés

    Clavier

    Les touches fonctionnent dans les deux onglets. Plusieurs lignes avec la même touche = une « cue » qui déclenche plusieurs actions.

    Médiathèque

    Stockée dans le navigateur (IndexedDB), réutilisable dans plusieurs calques.
